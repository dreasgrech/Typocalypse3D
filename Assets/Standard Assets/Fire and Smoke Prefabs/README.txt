Import the package into your Unity 3D project:

• Double Click the included .unitypackage file, then click the 'import' button making sure all files are selected.
— or —
• Assets > Import Package > select the included .unitypackage file > Open > then click on the 'import'
button making sure all files are selected.

Add to scene:

• The prefabs will be located in a folder called "Fire and Smoke Prefabs". Inside this folder there is are folders for the materials, textures, and prefabs themselves. Open the prefabs folder and select the desired prefab and simply drag it into your scene.


• Values of the praticle systems are tweakable via the relevant prefab, however it is not reccomended increasing the particle count any further due to performance concerns.


• Always remember when making changes to prefabs to do so in the Project window, this way all changes are made to the prefabs active in scenes.
