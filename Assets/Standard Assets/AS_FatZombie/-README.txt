
Thank you for buying Arabian Art Studios Fat Zombie!

DESCRIPTION:
	This Fat Zombie has all the basic materials and animations to help you get him up and running quickly. Ragdoll prefab is included for deaths!

	Look at the realtime web player demo here: http://dl.dropbox.com/u/36289/Transfer/MM_FatZombie_WebPlayer/WebPlayer.html

	Animations:
	- Idle
	- Walk
	- Run
	- Jump


USAGE:
	- We provide a basic prefab with animations hooked up using Mixamo's Animation State Machine.  To see this prefab at work open the demo scene: Scenes/AS_FatZombie_Gallery.
	- It is recommended that you change the Blend Weights under Quality Settings to be 4 bones for good deformation results.
	- A ragdoll prefab of the character is include for death states.
